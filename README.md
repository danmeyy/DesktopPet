# 桌面宠物 · dsh-pet overlay

一只蓝毛小女仆，浮在 Android 桌面上陪你。她会走来走去、自己换动作、看懂你在用什么 App，然后主动搭话。

![release](https://img.shields.io/github/v/release/danmeyy/DesktopPet?label=release&color=blue)
![license](https://img.shields.io/badge/license-MIT-green)
![android](https://img.shields.io/badge/Android-8.0%2B-3ddc84)

**独立 APK**：装上就能用，不 root、不 Shizuku、不 Xposed。最低 Android 8.0；鸿蒙 NEXT 装不了普通 APK。

## 她能做什么

| | |
|---|---|
| **住在桌面上** | 悬浮在所有应用上层，可拖动、可长按收起；横竖屏、分屏、折叠屏都会重新量尺寸，宠物不会压到刘海、状态栏和手势条 |
| **114 段动画** | 全部打进 APK，点一下随机换一段；待机时播完一段自己换下一段，不会卡在同一段 |
| **会走动** | 每隔 40–110 秒溜达到屏幕另一处，走路时播放踏步动画并按方向镜像；说「去左边 / 去右边 / 到中间 / 过来 / 站住 / 随便走」她听得懂 |
| **会看你在干嘛** | 开口前读一次屏（≤700 字，密码框整片跳过），所以能接着你正在看的内容聊；平时只记「现在前台是哪个 App」 |
| **会主动搭话** | 换应用、用久了会自己碎碎念；默认两次之间隔 75 秒，换应用后 3 分钟内有三成概率开口；0–8 点默认不出声，可在设置里打开 |
| **会记事** | 你随口说的作息、忌口、固定安排，她用 `<remember>` 打标存在本机；聊天上下文会按重要程度压缩成短文，分 5 档保存：3 天 / 7 天 / 15 天 / 30 天 / 永久 |
| **记得住又不会撑爆** | 摘要容量 50–2000 条可调，用到 50% / 80% / 90% / 95% / 100% 会提醒，满了先删 2% 最久没用到的；也能手动删或让她智能清（重复、寒暄、太久没用） |
| **用量看得见** | 今天 / 近七天 / 本月的说话次数、输入输出 token 与折算金额，数字取自接口回报的 `usage`，不按字数估 |
| **四套界面** | 默认 / Material 3 / HyperOS 4 / 毛玻璃，各自能调背景明暗、强调色、圆角、透明度与模糊；设置页分「大脑 / 日志 / 外观 / 介绍 / 关于」五页，切页不丢草稿 |
| **按品牌给路径** | 认得出小米、华为、OPPO、vivo、三星等，直接告诉你自启动、悬浮窗、电池优化该去哪儿点，点一行就跳到对应设置页 |

## 说话能力从哪来

两种来源，二选一即可：

| 模式 | 需要什么 | 说明 |
|---|---|---|
| **自填 API Key** | 一个 DeepSeek `sk-…` | 在 App 里填好，直连 `api.deepseek.com`，不依赖任何宿主 |
| **DSHBox 登录态** | DeepSeek Harness 桌面端或手机端在跑 | App 把请求打到 `http://127.0.0.1:3080/pet-brain/say`，由宿主插件代为调模型，不用自备 key |

用 DSHBox 的话，插件随 APK 自带：设置页「大脑 → 导出插件」会把它放到共享区（`/sdcard/DSHBox/pet-brain-plugin`），没共享区就放系统下载目录，再让 DSH 的会话装一次即可。

## 安装

1. 到 [Releases](https://github.com/danmeyy/DesktopPet/releases/latest) 下载 `pet.apk`。
2. 安装后依次给权限：**悬浮窗**（必须）、**无障碍**（读屏和"看见了什么"要用）、**通知**（可选）、**所有文件访问**（只有导出插件和读宿主日志才需要）。
3. 打开 App →「大脑」页填 API Key，或确认 DSHBox 在跑 → 点「启动宠物」。

小米 / HyperOS 额外注意：无障碍会被系统在闲置后关掉，要重新打开；并把自启动、后台弹出界面、电池策略都设成允许，否则关屏回来她可能就不在了。

## 隐私

- **发出去的**只有两样：你打的字（或她主动开口时的一句环境摘要），以及最近几句对话与摘要。不截屏、不上传应用列表、不传通讯录。
- **存在本机**：聊天记录只留最近三天的原话；摘要按 3/7/15/30/永久分档，过期自动清；习惯统计只记"哪个 App 用了多久"，不记内容；API Key 存在本机 SharedPreferences。
- **不读的东西**：锁屏、输入法、状态栏、通知栏、系统 UI；密码框连同子树整片跳过。
- 卸载 App，本机数据一起没。

## 目录

```
app/src/com/dsh/pet/    Java：悬浮窗、无障碍、日志、大脑请求

compose/                依赖解析与编译器（无 Gradle）
tools/                  帧转换、插件打包、APK 对比
plugin/                 宿主插件（随 APK 自带的同一份）
```

## 已知的小脾气

- 走路那几秒不吃触摸，手指会落到下面的应用上——这是为了走路不闪。
- 折叠屏展开会重算尺寸，但没实测过。
- 关机重启后不会自己回来（除非给了自启动），再打开一次 App 就行。
- 动画帧是 384×216 的 webp，四套界面共用，改界面不动图。
